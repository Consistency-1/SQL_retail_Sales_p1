# 🛍️ Retail Sales Analysis Using SQL Server

## 📌 Project Overview

This project focuses on analyzing retail sales data using **Microsoft SQL Server** to uncover meaningful business insights, understand customer purchasing behavior, and evaluate product category performance.

The project demonstrates practical SQL skills used by Data Analysts to clean data, perform exploratory data analysis (EDA), calculate business KPIs, identify sales trends, and answer real-world business questions.

The goal is to transform raw retail transaction data into actionable insights that can support data-driven business decisions.

## 🎯 Project Objectives

- **Database Setup:** Create and populate a retail sales database with transaction-level data.

- **Business Analysis:** Answer business questions using SQL queries and aggregate functions.
- **Sales Performance Analysis:** Identify high-performing categories, top customers, and peak sales periods.
- **Customer Analysis:** Analyze customer purchasing behavior by gender, age, and product category.

## 📊 Business Questions & SQL Analysis

### 1. Dataset Overview

Understand the size of the dataset, the number of unique customers, and the available product categories.

```sql
-- Total number of records
SELECT COUNT(*) AS total_records
FROM gold.Retail_Sales;

-- Number of unique customers
SELECT COUNT(DISTINCT customer_id) AS unique_customers
FROM gold.Retail_Sales;

-- Available product categories
SELECT DISTINCT category
FROM gold.Retail_Sales;
```

### 2. Sales on a Specific Date

Retrieve all transactions recorded on November 5, 2022.

```sql
SELECT *
FROM gold.Retail_Sales
WHERE sale_date = '2022-11-05';
```

### 3. Clothing Sales in November 2022

Identify clothing transactions where the quantity sold was at least four units.

```sql
SELECT *
FROM gold.Retail_Sales
WHERE category = 'Clothing'
  AND quantity >= 4
  AND sale_date >= '2022-11-01'
  AND sale_date < '2022-12-01';
```

### 4. Total Sales by Product Category

Calculate total revenue generated by each product category.

```sql
SELECT
    category,
    SUM(total_sale) AS total_sales
FROM gold.Retail_Sales
GROUP BY category
ORDER BY total_sales DESC;
```

### 5. Average Customer Age in the Beauty Category

Understand the average age of customers purchasing beauty products.

```sql
SELECT
    ROUND(AVG(CAST(age AS FLOAT)), 2) AS average_customer_age
FROM gold.Retail_Sales
WHERE category = 'Beauty'
  AND age IS NOT NULL;
```

### 6. High-Value Transactions

Identify transactions with a sales amount greater than 1,000.

```sql
SELECT
    transactions_id,
    customer_id,
    category,
    total_sale
FROM gold.Retail_Sales
WHERE total_sale > 1000
ORDER BY total_sale DESC;
```

### 7. Transactions by Gender and Category

Analyze transaction counts across product categories and customer gender.

```sql
SELECT
    category,
    gender,
    COUNT(*) AS transaction_count
FROM gold.Retail_Sales
GROUP BY category, gender
ORDER BY category, gender;
```

### 8. Best-Selling Month in Each Year

Identify the month with the highest average transaction value in each year. If multiple months tie for the highest average, all tied months are returned.

```sql
WITH monthly_sales AS (
    SELECT
        YEAR(sale_date) AS sale_year,
        MONTH(sale_date) AS sale_month,
        AVG(total_sale) AS average_sales
    FROM gold.Retail_Sales
    GROUP BY
        YEAR(sale_date),
        MONTH(sale_date)
),
ranked_months AS (
    SELECT
        sale_year,
        sale_month,
        average_sales,
        RANK() OVER (
            PARTITION BY sale_year
            ORDER BY average_sales DESC
        ) AS sales_rank
    FROM monthly_sales
)
SELECT
    sale_year,
    sale_month,
    ROUND(average_sales, 2) AS average_sales
FROM ranked_months
WHERE sales_rank = 1
ORDER BY sale_year;
```

*Note: This query identifies the month with the highest average transaction value, not necessarily the highest total monthly revenue.*

### 9. Top 5 Customers by Total Sales

Identify the five customers who contributed the most to total sales.

```sql
SELECT TOP 5
    customer_id,
    SUM(total_sale) AS total_sales
FROM gold.Retail_Sales
GROUP BY customer_id
ORDER BY total_sales DESC;
```

### 10. Unique Customers by Product Category

Measure how many distinct customers purchased products from each category.

```sql
SELECT
    category,
    COUNT(DISTINCT customer_id) AS unique_customers
FROM gold.Retail_Sales
GROUP BY category
ORDER BY unique_customers DESC;
```

### 11. Sales by Time of Day

Classify transactions into morning, afternoon, and evening shifts to understand purchasing activity throughout the day.

- **Morning:** Before 12:00 PM
- **Afternoon:** 12:00 PM through 5:59 PM
- **Evening:** 6:00 PM onward

```sql
WITH shift_analysis AS (
    SELECT
        CASE
            WHEN DATEPART(HOUR, sale_time) < 12
                THEN 'Morning'
            WHEN DATEPART(HOUR, sale_time) < 18
                THEN 'Afternoon'
            ELSE 'Evening'
        END AS sales_shift
    FROM gold.Retail_Sales
)
SELECT
    sales_shift,
    COUNT(*) AS transaction_count
FROM shift_analysis
GROUP BY sales_shift
ORDER BY
    CASE sales_shift
        WHEN 'Morning' THEN 1
        WHEN 'Afternoon' THEN 2
        WHEN 'Evening' THEN 3
    END;
```
